# WHMCS MCP Server

Model Context Protocol server for WHMCS (Web Host Manager Complete Solution) automation.

## 🎯 What It Does

Connects Claude AI with WHMCS API for:
- Client management automation
- Service provisioning workflows
- Billing operations through natural language
- Integration with hosting automation systems

## 🛠️ Tech Stack

- **Language**: TypeScript
- **Protocol**: Model Context Protocol (Anthropic)
- **API**: WHMCS API
- **Use Case**: Web hosting automation

## 🚀 Why I Built This

WHMCS powers thousands of hosting companies but lacks modern AI integration. This MCP server enables AI assistants to interact with WHMCS installations, automating common tasks like client onboarding, service management, and billing operations.

## 💼 Professional Context

Built as part of my specialization in automation systems and integrations at Sourei, where I develop WHMCS modules and workflow automation tools for hosting companies.
